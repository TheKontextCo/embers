# Building a Second Brain

Building a second brain is a practical way to keep useful ideas available when
real work calls for them. Capture is only the beginning; the value comes from
connecting, distilling, and resurfacing what matters.

## Knowledge System

The Weekly Review supplies the rhythm. Progressive Summarization makes longer
notes easier to reuse without discarding their source.

## Working rule

Organize information around active work instead of building an archive for its
own sake. Preserve the source beneath every summary.
